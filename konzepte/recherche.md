# Recherche Lackschichtmessung (23.11.2026)

Quellen: YouTube gD5KB-bC57s (Lackmessgerät ET 111, Unfallprüfung), _0LGbM5CPAU (digital paint gauge), Kontaktbogen /tmp.

- Gerät: kompaktes schwarzes Handgerät, etwa so groß wie ein kleines Handy, dicker; runde Sensorspitze am oberen Ende.
- Haltung: eine Hand, Gerät quer oder hochkant, Display zum Prüfer gedreht; Sensorspitze wird senkrecht und flach auf den Lack gedrückt, kurz halten, Wert ablesen, nächster Punkt.
- Ablauf: Bauteil für Bauteil (Tür links, Kotflügel, Haube …), mehrere Punkte je Bauteil in einer Reihe.
- Werte: Serie ca. 100–160 µm; nachlackiert ca. 200–400 µm; Spachtel 500–1000+ µm (im Video 113 → 183 → 321 → 1025 µm).
- Für Video-Prompts: Hand bleibt am Gerät, Gerät setzt nacheinander an 3 Punkten auf (Kotflügel vorn, Kotflügel Mitte an der Delle, Tür vorn), zwischen den Punkten kurz abheben, nie loslassen. Werte kommen im Code als Pins (Display im Video ohne lesbare Zahl).
